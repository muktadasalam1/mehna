# Mehna Color System

Dual-theme (dark/light) with CSS custom properties. Font: Tajawal.

## Shared Accent Colors

| Token | Hex | Usage |
|-------|-----|-------|
| `--accent` | `#FF8C00` | Primary brand (orange) |
| `--accent-hover` | `#FFA500` | Hover state |
| `--accent-soft` | `rgba(255,140,0,0.10)` | Subtle backgrounds |
| `--accent-border` | `rgba(255,140,0,0.25)` | Borders |
| `--success` | `#22C55E` | Active, verified |
| `--danger` | `#EF4444` | Error, inactive, delete |
| `--warning` | `#F59E0B` | Pending, admin badge |

## Spacing & Radius

- Spacing: 8px grid (`--sp-1` 4px to `--sp-16` 64px)
- Radius: `--r-sm` 6px, `--r-md` 10px, `--r-lg` 14px, `--r-xl` 20px

## Layout

- Sidebar width: 260px (collapsed 72px)
- Font: Tajawal (Google Fonts)
- Direction: RTL (Arabic)
